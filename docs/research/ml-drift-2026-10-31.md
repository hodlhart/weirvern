# TMP-3 drift monitoring and retrain policy — 2026-10-31

**Purpose:** a model can stay within its threshold while its score distribution moves. Drift
monitoring compares a current time split with the preceding split per model/host, records the
result, and recommends a review. It never retrains, alerts or pages.

## Schema

Additive `weirvern/schema/039_ml_drift.sql`:

`computed_at, window_start, model_name, src_addr, role, metric, baseline_value,
current_value, drift_score, status, evidence` — `ReplacingMergeTree`, 90-day TTL.

## Metric

`psi(baseline, current)` uses baseline quantile edges. `classify` is three words:

- `stable` < 0.10
- `watch` 0.10–0.25
- `drift` ≥ 0.25

`retrain_policy(rows)` returns `trigger`, affected model names and `automatic:false`. A
retrain remains the existing gate/review action, not a side effect of this module.

## Run

`run(client, hours=24, baseline_hours=24, min_samples=10)` reads `ml_window_scores` for the
current and preceding windows, joins optional `host_roles`, writes `ml_drift`, and returns
`notices` plus the manual retrain recommendation. A failed read is `available:false` with the
reason. It is wired into the hourly shadow tick and the Models health channel.

## Verification

- Identical distributions: PSI **0.0**; shifted distribution: **>0.25**; small samples: 0.
- 48 historical model/host pairs on the disposable ClickHouse: **16 drift, 14 watch**.
  DBSCAN **5 drift**, Gradient Boosting **7**, Isolation Forest **4**, Adaptive Baseline **0**;
  example Isolation Forest pair PSI **0.9301**.
- `retrain_policy` returns `automatic:false`; no alert-table write.
- `tests/test_drift.py`: 6 tests; gate PASS.
- Dashboard: `shadow_overview` now includes the `drift` channel, so the Models health line
  names it as collecting/empty/unavailable rather than omitting it.

## Limits

- The historical backfill above is the disposable shadow corpus, not a claim about production
  model behaviour; live drift starts when the release is deployed.
- PSI is sensitive to sample size and quantile edge choice; `min_samples` is enforced and the
  result is a notice, not a verdict.
- No automatic retrain, no model artifact change and no production deployment.
