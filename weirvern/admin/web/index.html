About this interface

Read-only. Every number here comes from ClickHouse via the same query layer the CLI and TUI use, so all three agree by construction.

There are no lifecycle controls in this UI by design. Starting, stopping and applying stay in the CLI and TUI. That is what makes it safe to reach this on a LAN port: nothing an HTTP request can do can change the deployment. Adding buttons here would require authentication first.

Hostnames come from reverse DNS. By default only private addresses are resolved, so the lookup stays on your network; set WEIRVERN_REVERSE_DNS=all to resolve public addresses too, which sends them to your resolver.
